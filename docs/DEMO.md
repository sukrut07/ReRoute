# Demo

Primary scenario:
1. Customer enters: "I want to claim my hospital expenses."
2. Reroute creates a health-insurance journey.
3. Customer uploads synthetic documents.
4. Document extraction populates fields.
5. A deliberate DOB mismatch is introduced.
6. Verification blocks progression.
7. Reroute explains the conflict.
8. Customer resolves it.
9. Journey re-verifies.
10. Risk intelligence shows transparent signals.
11. Human-review path is available.
12. Journey completes.

Use demo mode so the core flow is deterministic and never depends on live third-party APIs.
