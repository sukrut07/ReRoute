# Reroute Design System

## Direction
Minimal neo-brutalist fintech UI inspired by the supplied Pressera reference.

## Principles
- High contrast
- Strong 1–2px borders
- Off-white / near-black surfaces
- Monospace labels with bold sans-serif headings
- Restrained green, amber, red and blue state colors
- Minimal rounded corners
- No decorative gradients or animated backgrounds
- Motion only for meaningful state transitions

## Product visual language
Reroute uses route/checkpoint metaphors:
- Green = verified / complete
- Amber = attention / uncertainty
- Red = conflict / blocked
- Blue = informational
- Black = primary action / structure

## Components
- RouteCard
- JourneyCheckpoint
- EvidenceCard
- ConflictPanel
- RerouteBanner
- RiskSignal
- ReviewPacket
- MetricCard
- Timeline
- EvidenceDrawer
- StatusBadge
