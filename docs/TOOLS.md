# Open-Source Toolkit

## UI
- shadcn/ui — composable accessible React components
- Radix UI — accessible primitives
- Lucide — open-source icons
- React Flow — interactive node/edge graphs for journey and evidence views
- Recharts — lightweight React charts
- TanStack Query — server-state fetching and caching
- React Dropzone — document upload UX

## AI / workflow
- LangGraph — stateful agent/workflow orchestration
- FastAPI — Python API layer
- Qdrant or pgvector — vector retrieval
- Mermaid — architecture and journey diagrams

## Document intelligence
- Tesseract — open-source OCR
- PaddleOCR — OCR/document extraction option
- Microsoft Presidio — optional PII detection/redaction for test pipelines

## Optional extensions
- n8n — workflow automation
- Sarvam — optional Indic language/voice layer

## Reroute-specific use
- shadcn/Radix/Lucide for the neo-brutalist UI
- React Flow for an interactive journey/evidence graph
- Recharts for friction, completion and risk-signal analytics
- TanStack Query for journey state
- React Dropzone for evidence upload
- LangGraph for state transitions and explainable orchestration
- OCR/VLM abstraction for synthetic document extraction

Review package licenses before redistribution and pin production dependencies.
